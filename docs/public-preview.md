## Объём

Python-скрипт `scripts/export_preview.py` формирует 26 общедоступных страниц из существующего FastAPI/Jinja-приложения. Исходный Python-проект и SQLite остаются отдельными; на GitHub Pages не переносятся сервер, БД, admin/API, корзина, заказы, заявки, runtime-файлы или токены форм. Это версия для демонстрации, а не развёрнутый Python backend.

Доступны главная, каталог 30 позиций, фотографии, семейства HDSR/RSR/ERB, характеристики AERZEN, применение, сервис, компания, статьи, контакты и информационные страницы. Поиск и фильтры производителя/типа/категории выполняются браузером через `preview-assets/public-preview.js`, поддерживаются URL-параметры и Back. Без JavaScript отображается весь каталог с пояснением. Нет новых пакетов или внешних UI-компонентов; существующая система UI Pattern Forge сохранена.

Поля заявок выключены; POST-формы заменены неотправляемыми блоками. Токены, nonce и структурированные коммерческие данные из копии удаляются. Аналитика, реклама и платёжные действия не подключены. Настройки cookies сохраняются локально, политика демоверсии не обещает серверных сессий; раскрыт технический сбор IP хостингом GitHub. Все страницы noindex,nofollow, robots.txt запрещает индексацию. Это не ограничение публичного доступа.

[Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) подтверждает статическое размещение и техническое журналирование посещений. Конфигурация проверена по [официальному API Pages](https://docs.github.com/en/rest/pages/pages). Sites-хостинг проверен как вариант: его Worker/Vinext не переносит существующий Python-сервер; стек проекта ради размещения не менялся.
