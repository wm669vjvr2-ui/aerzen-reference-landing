# Фотографии ERSTVAK ERB

15.10.2026. Официальные карточки ERB-50/65/80/100/125/150 и [страница серии](https://erstvak.com/brands/rotornye-vozdukhoduvki-erstevak/erstevak-seriya-erb/) прочитаны. Прямые загрузки из shell возвращали timeout, но страницы успешно открылись в IAB; изображения экспортированы документированным pageAssets.bundle из уже наблюдаемой страницы.

Шесть миниатюр карточек имеют разные URL, но одинаковый SHA-256 и вид общего агрегата. Поэтому они не названы шестью уникальными фотографиями моделей. В интерфейсе для всех шести ERB используется один более качественный реальный снимок серии: `static/images/models/erb/erb-assembly.png`, 523×565, из официальной медиагалереи. Подпись сообщает, что это общий вид серии и исполнение конкретной модели может отличаться. Логотип, обнаруженный среди изображений страницы, не использован как фотография оборудования.

Первичные карточки: [ERB-50](https://erstvak.com/product/rotornaya-vozdukhoduvka-ruts-erstevak-erb-50/), [65](https://erstvak.com/product/rotornaya-vozdukhoduvka-ruts-erstevak-erb-65/), [80](https://erstvak.com/product/rotornaya-vozdukhoduvka-ruts-erstevak-erb-80/), [100](https://erstvak.com/product/rotornaya-vozdukhoduvka-ruts-erstevak-erb-100/), [125](https://erstvak.com/product/rotornaya-vozdukhoduvka-ruts-erstevak-erb-125/), [150](https://erstvak.com/product/rotornaya-vozdukhoduvka-ruts-erstevak-erb-150/).

Точный URL файла, контрольная сумма, исходные миниатюры и сопоставление всех шести строк — model-photo-manifest-erb.json. Изображения просмотрены через view_image, декодирование проверено. Использованы оригинальные байты без ретуши, удаления брендов или генерации ИИ. Наличие изображения не означает поставку этих моделей.
