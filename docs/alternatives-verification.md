# Проверка справочника альтернатив

Дата: 14 октября 2026 года. Проверены отдельный проект `aerzen-reference-landing`, его серверный код, справочные данные и реальные Jinja-шаблоны. Исходный `aerzen-site` не редактировался. Тесты используют собственные временные копии контента и шаблонов, отдельные SQLite-базы и только искусственные данные обращения/продавца.

Итог после удаления переходов на основной сайт: `../aerzen-site/.venv/bin/python -m pytest -q` — **18 passed, 1 warning**. Это 11 существующих проверок и 7 сценариев нового модуля: шесть функций, одна из которых параметризована для preview и production. Дополнительный регрессионный сценарий проверяет единицы измерения и неподтверждённые сведения ERB; существующая проверка страниц подтверждает отсутствие ссылок на основной сайт и наличие местной формы на hub и каждой странице серии.

| Область | Статус | Доказательство / ограничение |
| --- | --- | --- |
| Справочные страницы | готово | Hub `/alternatives` и три страницы серий возвращают 200, имеют по одному различающемуся H1 и собственному canonical; неизвестная серия возвращает 404 |
| Раскрытие отсутствия поставки | готово | На всех четырёх страницах присутствует «Эти модели не поставляем.»; в данных каждой серии `supply_status=not_supplied` |
| Разделение справочника и товаров | готово | `Content.alternatives` читает отдельный `alternatives.json`; китайские/ERB серии отсутствуют в `Content.products`, корзине и товарном фиде. Добавление каждой серии в корзину возвращает 422 даже при включённой тестовой коммерции; подтверждённый искусственный SKU успешно добавляется и попадает в фид |
| Расход HDSR и RSR | готово | 11 HDSR и 6 RSR: каждый исходный диапазон `m3/min` умножен на 60; результат согласован и с числовыми `flow_m3_h`, и с отображаемой строкой |
| Расход ERB | готово | Шесть моделей: исходные `m3/h` сохранены без повторного умножения на 60; диапазоны не названы Нм³/ч |
| Исключения по давлению | готово | Для HDSR150 сохранено 9,8–58,8 кПа. У RSR50/65/100 — 9,8–78,4; у RSR80/125/150 — 9,8–98. Для ERB показано «до 100» кПа, в пояснении указан пересчёт 1000 мбар в 100 кПа |
| Мощность ERB-100 | готово | Из-за противоречия источника числовая мощность не опубликована; строка «Требует уточнения» присутствует в данных и на странице |
| Происхождение ERB | готово | `country_status=unconfirmed`; ERB не назван китайской серией в H1, на странице явно указано, что китайское происхождение не подтверждено |
| Фото и обещания замены | готово | Единственное предметное фото на странице серии подписано как AERZEN Delta Blower, а не китайская/ERB модель. Текст требует подбора по рабочей точке и не обещает прямую взаимозаменяемость |
| Отсутствие переходов на основной сайт | готово | На hub и всех трёх страницах нет ссылок с hostname основного сайта из `site.source_url`; HTTP-редиректов и meta refresh нет. Заявка заполняется на этой площадке. На странице нет Product/Offer/AggregateOffer schema |
| Форма подбора альтернативы | готово | На hub и каждой странице есть местная форма `/requests/task` с пустым `product_slug`; выбранная серия передаётся в редактируемом сообщении на странице серии. Проверено сохранение искусственного обращения с пустым product slug |
| XSS в предзаполнении | готово | Подстановка имени с `</textarea><script>…` не закрывает поле и не создаёт исполняемый script; текст остаётся содержимым textarea |
| Индексация | готово | В production sitemap содержит hub и три страницы серий. В preview sitemap пустой, страницы имеют `X-Robots-Tag: noindex, nofollow` |
| Реальный приём заявок | заблокировано | Тесты включают обработку только в искусственной конфигурации. Реальная юридическая готовность, доставка заявок оператору и сроки хранения не подтверждены |
| Покупка справочных моделей | не применимо | HDSR, RSR и ERB не поставляются этим сайтом; коммерческие SKU и платёжные предложения для них не созданы |
| Реальная взаимозаменяемость и спрос | заблокировано | Диапазоны не устанавливают совпадение рабочей точки. Требуется инженерный расчёт конкретной конфигурации; фактический спрос на модели не подтверждён |
| Публичная публикация новых страниц | заблокировано | Проверка реализации и тестов не подтверждает наличие публичного HTTPS размещения или обновление production |

Первичные ссылки, происхождение и дата проверки находятся в `content/alternatives.json`. Настоящий отчёт проверяет внутреннюю согласованность пересчётов и поведение реализации; первичные сайты производителей повторно не запрашивались в ходе этой проверки.
