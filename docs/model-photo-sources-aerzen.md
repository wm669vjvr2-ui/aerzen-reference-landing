# Фотографии AERZEN

Проверено 15.10.2026. Семь используемых изображений получены с официальных страниц производителя и сохранены в `static/images/models/aerzen/`. Файлы — PNG 1000×1000; сигнатура, размеры, ненулевой объём и SHA-256 проверены. Каждый файл открыт через `view_image` и визуально осмотрен. Локальные изображения не генерировались ИИ и не взяты с основного сайта пользователя.

Галереи: Delta Blower — закрытый агрегат и вариант без кожуха; Delta Hybrid — закрытый агрегат и приборы контроля; Delta Screw — закрытый агрегат и внутренний вид VM45E E-Design. Неиспользуемые детальные снимки другого типоразмера GM исключены из текущего набора.

Полные URLs файлов, размеры, контрольные суммы, подписи, источник и машинное сопоставление всех семи позиций находятся в `docs/aerzen-photo-manifest.json`.

## Доступ и права

Страницы и файлы доступны без авторизации. Публичный доступ не устанавливает лицензию на повторное использование. Разрешение правообладателя на публикацию на отдельном коммерческом сайте не подтверждено; в manifest указан `license_status: unknown`, назначение — локальный просмотр до подтверждения прав или замены на разрешённые изображения. Фото не подтверждают наличие на складе или комплектацию предложения.

## Получение и ограничения

Для веб-чтения применён Agent Reach: Jina Reader вернул `401 AuthenticationRequiredError` с причиной репутации сети, установленный CLI Agent Reach не найден. Поиск выполнен web fallback; оригинальный HTML официальных страниц и связанные изображения прочитаны через обычные HTTPS-запросы. Страницы поставщика `aerzen.net.ru` для отдельных GM в локальной сети не загрузились (TLS timeout). Случайные изображения из объявлений о б/у оборудовании не используются.
