## Точность привязки

Производители подписывают выбранные фотографии как изображения **серии**, без указания конкретного типоразмера. Поэтому `scope` каждого файла и семейства равен `series`, а `specific_model_verified` равен `false`. Каждая модель получает проверенное фото своей серии; одну и ту же фотографию нельзя выдавать за отдельный подтверждённый снимок конкретного артикула. Подпись для интерфейса: «Фото серии. Исполнение конкретной модели может отличаться».

Для HDSR основной снимок — `huadong-hdsr-unit.webp`; для RSR — `mingtian-rsr-unit.webp`. Дополнительные виды перечислены в `gallery_asset_ids`. На RSR-фото сохранён знак производителя Shan Gu; на HDSR сохранён водяной знак с контактным адресом. Кадрирование, удаление логотипов и водяных знаков не выполнялись. Изображения только перекодированы из JPEG в WebP с сохранением исходных размеров и композиции. Общий объём шести файлов — около 233 КБ.

## Права и публикация

Публичная доступность фото на сайте производителя не подтверждает свободную лицензию для перераспространения. У HUADONG в подвале страницы указано «All Rights Reserved»; разрешение на использование этих файлов третьими лицами не найдено. У MINGTIAN отдельная лицензия на фотографии на проверенной странице не указана. `license_status` сохранён как `unknown`; файлы подготовлены для локального просмотра по указанию пользователя. До публичной публикации требуется подтвердить разрешение правообладателей либо заменить фотографии активами с проверенной лицензией. Доступность изображений не меняет статус «Эти модели не поставляем».

## Получение и проверка

Agent Reach применён для маршрутизации веб-чтения. Jina Reader вернул HTTP 401 с ограничением анонимного доступа; страницы были получены через `web` и обычный HTTP GET. URL снимков извлечены из реальных `img src`/`data-src` страниц, затем проверены загрузкой и визуальным просмотром. Не использовались сгенерированные изображения, снимки другой марки, ссылки на случайные похожие товары или искусственное назначение фотографии серии конкретному типоразмеру.
