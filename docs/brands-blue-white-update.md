# Обновление каталога и оформления — 16.10.2026

## Выполненные изменения

Сине-белое оформление и фотография воздуходувного агрегата AERZEN вместо цеха с кранами. Основной вход — по брендам Lutos, Robuschi, Kaeser, Atlas Copco, Kubicek, Busch и Pedro Gil. Для каждой марки есть отдельная страница, проверенные серии, реальные фото соответствующих серий и ссылки на первичные данные производителя. AERZEN сохранён; из китайских серий оставлен только Huadong HDSR.

30 карточек: 12 новых серий семи марок, 11 моделей Huadong и 7 позиций AERZEN. Фото Huadong и моделей GM относятся к серии/примеру исполнения, как указано в подписях, а не заявлены уникальными снимками каждого типоразмера. Robushi поддерживается как поисковый вариант Robuschi. Lutos DT описан как прежняя линейка, включённая в ZL по сообщению Atlas Copco.

Удалены публичные страницы Mingtian/ERSTVAK, блог, применение/пневмотранспорт, расчёты/сервисные сценарии. Масло оставлено самостоятельной страницей `/oil`. Навигация, поиск, каталог и sitemap обновлены. Старые статические HTML/фото исключены из новой ветки публикации целиком, чтобы удалённые разделы не оставались по прямым ссылкам.

После следующего указания пользователя исходный SVG логотипа с его сайта подключён без изменений в шапку и подвал. Отдельный PNG больше не требуется; проверка описана в `docs/logo-update-2026-10-16.md`.
