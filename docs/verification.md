В консоли ошибок/предупреждений нет. Reduced motion проверен по CSS; эмуляция системного предпочтения не выполнялась. Снимки — docs/previews/.

В тестах осталось одно предупреждение Starlette: текущий `httpx`-адаптер TestClient объявлен устаревшим. Ошибок тестов нет; новые пакеты ради предупреждения не устанавливались.

Проверка оригинального `aerzen-site` была только чтением. На момент проверки его `git status --short` показывал изменения `static/css/site.css`, `static/js/site.js`, `templates/_macros.html`, `templates/about.html`, `templates/repair.html` и новый `docs/photo-gallery.md`. Эти изменения не выполнялись в рамках данной проверки и автоматически не откатывались.
