Запрещены продажа самих фотографий без существенного изменения и сбор библиотеки изображений для конкурирующего фотосервиса. Эти фотографии визуально проверены: заметных узнаваемых людей и продуктовых логотипов не обнаружено.

Для пользовательского интерфейса можно добавить строку: «Фотографии: Ant Rozetsky, Patrick Federi, Dave Meckler / Unsplash» со ссылками на соответствующие страницы.

Не следует подписывать изображения «наш склад», «наше производство», «наш проект» или представлять их как фотографии конкретных моделей AERZEN, HDSR, RSR, ERB. Для такого содержания нужны реальные фотографии соответствующего оборудования от владельца сайта с подтверждённым правом использования.

## Обработка и ограничения

Файлы получены в JPEG с уменьшением размера через официальный CDN. Локальная генеративная обработка, замена надписей и подделка маркировок не выполнялись. Допустимы адаптивное кадрирование и затемнение CSS на первом экране; это не меняет подпись об иллюстративном назначении.

Страницы фотографий доступны в веб-поиске и подтверждают авторство и тип лицензии. Прямое открытие страницы общей лицензии вернуло 429; её текст и правила подтверждены официальной поисковой выдачей и справочным центром Unsplash. Файлы CDN фактически скачаны и открыты локально для визуальной проверки.
