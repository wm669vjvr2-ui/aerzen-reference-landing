# Референс отдельного сайта

Обновлено 14.10.2026, Europe/Moscow. Этот документ фиксирует проверенные источники и ограничения, а не подтверждает пиксельное совпадение.

## Текущее поручение

Пользователь подтвердил **Erstvak.com и модели AERZEN**, выбрал чёрно-жёлтую палитру и поручил реализовать отдельный сайт без нового показа концептов. Старый блок «Знаю модель / Есть задача / Ремонт» и прежние фотографии исключены. Последующее уточнение разрешает реальные фотографии из интернета; использованы лицензированные тематические снимки Unsplash.

Раннее поручение об учёте четырёх AERZEN-сайтов заменено последним выбором Erstvak. Работа остаётся в `aerzen-reference-landing`, ветка `codex/reference-landing`; исходный проект `aerzen-site` и его репозиторий не редактируются. На основной сайт переходов нет. Справочные HDSR, RSR и ERB не представлены как поставляемые товары.

Agent Reach применён для выбора способа чтения. Jina Reader вернул `AuthenticationRequiredError` из-за репутации сети; использована доступная веб-выдача. Платный доступ и ограничения источников не обходились.

Минимальный совместимый вариант — собственные HTML/CSS в существующем Python-стеке, нативные `details` и `dialog`. Права на снимки Refero и фотоматериалы конкурентов не предполагаются.
