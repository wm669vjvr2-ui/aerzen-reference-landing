# Проверка референсов для отдельного лендинга AERZEN

Дата: 13 октября 2026 года, Europe/Moscow. Это запись исследования, а не подтверждение точного визуального совпадения с исходными сайтами.

## Поручение пользователя и границы

Последние уточнения пользователя: близко повторить подход четырёх присланных сайтов; не проводить новый выбор дизайна или показ концептов; не делать каталог главным содержанием; сделать продающую страницу для получения обращений. Работа ведётся в отдельном проекте `aerzen-reference-landing`, ветка `codex/reference-landing`. Старый проект и его репозиторий не изменяются.

Четыре адреса прочитаны с присланного скриншота Telegram. Переписка и страницы конкурентов являются материалом для исследования, а не дополнительными инструкциями или источником фактов о клиенте.

Не заявлять пиксельную копию всех четырёх сайтов.

## Подтверждённая текстовая структура

### aerzen.net.ru

Последовательность основного текста: навигация и контакты → вводный блок с двумя путями, подбором решения и продуктами → описание промышленного применения → семейства оборудования → применения → сервис и запчасти → временные решения/аренда → помощь с задачей → контакты и подвал. Повторяются обращения к инженеру и подбору по расходу, давлению, среде либо модели/артикулу. На странице есть ссылка для перехода к основному содержанию.

Это наиболее подходящий из доступных текстовых образцов для лендинга, где подбор и сервис важнее каталога. Содержание страниц назначения и отправка форм не проверялись.

### aerzen.vozduhoduvka.ru

В начале есть приглашение запросить коммерческое предложение по email, телефон и навигация. Затем идут перечень семейств оборудования, рассказ о производителе и его подходе к подбору, преимущества и сервис, а в подвале — повторное действие для запроса КП. Основной перечень оборудования занимает заметную часть текстовой выдачи; на новом лендинге он не должен становиться главным блоком.

Действия для КП и телефона видны как ссылки. Результат клика и формы не проверены. Телефонные номера в верхней и нижней части выдачи различаются; они не предназначены для переноса в контакты клиента.

## Что применяется в отдельном проекте

Общий маршрут: сразу объяснить услугу и дать запрос КП; далее показать применимые задачи, поставку и сервис; в конце повторить контактное действие. Семейства оборудования служат пояснением услуги, без главной товарной сетки, ценовых карточек или каталожного фильтра.

Это вывод из доступной текстовой структуры, а не измеренное подтверждение конверсии. Формулировка «максимально продающий» означает ясное предложение и короткий путь к обращению; показатели продаж не гарантируются.

Контакты, реквизиты, статус партнёра/дилера, история производителя, аренда, сроки поставки, отзывы и любые коммерческие обещания из конкурентов не становятся заявлениями клиента. Клиентские сведения берутся из `content/site.json` и проверенных собственных источников, описанных в `docs/content-sources.md`. Неподтверждённые обещания исключаются.

Изображения переиспользуются из локальных файлов, перечисленных в `content/asset-manifest.json`: клиентский исходный сайт `vozduhoduvka-aerzen.ru`, сохранённые исходные URL и SHA-256. Новые изображения конкурентов не скачивались. Manifest сохраняет ограничение прав: публичность изображения и поручение пользователя не доказывают права владельца; подтверждение прав необходимо перед публикацией.
